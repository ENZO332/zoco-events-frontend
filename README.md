# Zoco Events Frontend

Dashboard para gestión de bares y eventos de Tucumán.

## Stack
- React + Vite
- CSS puro con variables

## Instalación
```bash
npm install
npm run dev
```

## Configuración
La URL de la API está en `src/services/eventService.js`. Por defecto apunta al deploy en Railway.

## Deploy
Deployado en Vercel: https://zoco-events-frontend.vercel.app/
